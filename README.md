# 重生2012比特币大亨

模拟重生回到 2012 年，靠比特币和房产逆袭成首富。

一款单机文字经营模拟游戏，带你重回 2012 年那个遍地黄金的年代。初始资金 ¥5,000，白手起家，从 5 千块到亿万家产。

## 玩法亮点

**逆天改命**
18 岁重生，身无分文。从发传单、端盘子到敲代码，一步步攒下第一桶金；在比特币还是几块钱的时候疯狂囤币，看着它一路涨到六位数；低买高卖房产，租金躺着收。

**多样人生**
随机三选一事件，是借钱梭哈，还是稳扎稳打？每个选择都在改写你的命运。

**输了还能重来**
触发危机？东山再起。
